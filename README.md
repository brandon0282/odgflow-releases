# odgFLOW releases

Public APK releases for [odgFLOW](https://github.com/brandon0282/odgflow) — an on-device Android dictation overlay.

## Install

Grab the latest APK from the Releases page at right, or use this stable link that always points at the newest version:

**https://github.com/brandon0282/odgflow-releases/releases/latest/download/odgFLOW.apk**

Open the file on your Android phone, allow install-from-unknown-sources if prompted, and launch odgFLOW. Requires Android 13 (API 33) or newer.

## Privacy

Audio is transcribed locally on your phone via [whisper.cpp](https://github.com/ggerganov/whisper.cpp). Nothing is uploaded. The only network request the app makes is to this repo's Releases API to check for updates. See the in-app Privacy pledge for details.

## Source

Source code is in a separate private repository. This repo exists only to distribute signed release builds.
